MARK GIAN CALICDAN PROFILE WEBSITE

Files included:
- index.html: page content and the supplied photo/logo references
- style.css: responsive poster layout, soft white fade at the bottom of the beach cover, and clean non-overlapping logos
- image files: required cover, profile, social-media, editing-app and Google Drive logos

To use in Spck Editor:
1. Extract the ZIP file.
2. Open/import the sitework folder (or move its contents together into one project folder).
3. Open index.html and preview it.
4. Keep index.html, style.css and all image files together in the same folder.

Links included: phone, email, Facebook, Instagram, Discord, TikTok, Telegram and Google Drive projects.
